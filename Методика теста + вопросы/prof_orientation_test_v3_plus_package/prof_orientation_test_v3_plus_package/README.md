# Пакет документов: профориентационный тест v3+

В архив включены документы по профориентационному тесту для направлений:

- аддитивные технологии;
- 3D-моделирование;
- 3D-печать;
- постобработка изделий;
- БПЛА;
- конструирование;
- программирование;
- управление робототехническими и беспилотными системами.

## Состав архива

1. `01_full_document_v3_plus.md` — полный документ с механикой, направлениями, карточками результатов и профессиями с кодами.
2. `02_short_version.md` — краткая версия для согласования.
3. `03_methodical_note.md` — методическая записка для педагога / технопарка / центра допобразования.
4. `04_site_config.json` — JSON-конфиг для внедрения на сайт.
5. `05_simulation_results.csv` — результаты симуляции проверки механики.
6. `06_scoring_pseudocode.md` — псевдокод подсчёта результата.
