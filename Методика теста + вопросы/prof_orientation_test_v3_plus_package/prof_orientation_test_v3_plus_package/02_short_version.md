- Итоговые карточки направлений.
- Отдельный слой “интерес” и “готовность”.

- Шкала уверенности.
- Методическая записка.

## Вопросы

- 10 вопросов с множественным выбором.
- В каждом вопросе выбрать не больше 2 вариантов.
- Q1–Q8: интерес.
- Q9–Q10: готовность и контрольные предпочтения.
- 6 слайдеров интереса по направлениям.
- 5 слайдеров готовности.

## Ключевая защита

Если пользователь выбирает больше 2 вариантов, баллы за вопрос ограничиваются:

```text
max_points_for_question = points_per_answer * 2
points_per_selected = max_points_for_question / selected_count
```

## Итог

Система показывает один из вариантов:

| Тип результата                         | Когда показывать                                  |
| -------------------------------------- | ------------------------------------------------- |
| Одиночный профиль, высокая уверенность | Явно лидирует одно направление, нет противоречий  |
| Одиночный профиль, средняя уверенность | Направление лидирует, но нужно проверить проектом |
| Смешанный профиль                      | Два направления близки                            |
| Широкий технический интерес            | Всё интересно или выбрано слишком много вариантов |
| Низкая определённость                  | Слайдеры низкие, интерес пока не проявлен         |

## Что показывать в карточке результата

1. Название профиля.
2. Уровень уверенности.
3. Почему подходит.
4. Профессии с кодами.
5. Что попробовать.
6. Что изучать.
7. Мини-проект.
