# Методическая записка к профориентационному тесту v3

> Источник кодов профессий/должностей: ОК 016-2025 / ОКПДТР-2025. Классификатор введён приказом Росстандарта от 16.05.2025 № 423-ст с датой введения 01.01.2026; объектами классификации являются профессии рабочих и должности служащих.

## Назначение

Тест предназначен для первичной профориентации школьников по двум техническим блокам: **аддитивные технологии** и **БПЛА**.

Он помогает не выбрать профессию окончательно, а определить, какие виды деятельности стоит попробовать первыми.

## Структура

- 6 направлений.
- 10 вопросов с множественным выбором.
- 6 слайдеров интереса.
- 5 слайдеров готовности.
- Итоговая карточка результата.

## Принципы интерпретации

### 1. Интерес отдельно от готовности

Школьник может интересоваться направлением, но пока не быть готовым к его требованиям. Например, интерес к программированию БПЛА требует проверки готовности к коду, математике и отладке.

### 2. Смешанный результат — нормальный результат

Если два направления близки, тест не должен насильно выбирать одно. Смешанный профиль превращается в проект на стыке направлений.

### 3. Нет ложной точности

При широких, случайных или противоречивых ответах тест снижает уверенность и предлагает практические пробы.

## Уровни уверенности

| Уровень               | Действие педагога                       |
| --------------------- | --------------------------------------- |
| Высокая               | Дать профильный проект или кружок       |
| Средняя               | Дать короткую пробу на 1–2 занятия      |
| Смешанная             | Дать проект на стыке двух направлений   |
| Широкий интерес       | Дать 2–3 разных мини-пробы              |
| Низкая определённость | Начать с демонстрации и простых заданий |

## Рекомендуемый сценарий занятия

1. Школьник проходит тест.
2. Педагог показывает результат и объясняет его простыми словами.
3. Школьник выбирает один мини-проект из результата.
4. После выполнения проекта проводится короткая рефлексия:
   - что понравилось;
   - что оказалось сложным;
   - хочется ли продолжать;
   - какое направление попробовать следующим.

## Дисклеймер для сайта

> Этот тест помогает выбрать техническое направление для первого знакомства. Результат не является окончательным выбором профессии и не заменяет консультацию педагога или профориентолога. Лучший способ проверить интерес — попробовать небольшой практический проект.

## Пилотная проверка

Перед массовым запуском рекомендуется проверить тест на 20–30 школьниках.

| Что проверить              | Нормальный признак                                                |
| -------------------------- | ----------------------------------------------------------------- |
| Понятность формулировок    | Большинство проходит без дополнительных объяснений                |
| Совпадение с самоощущением | Участник говорит: “похоже на меня”                                |
| Работа смешанных профилей  | Смешанные результаты воспринимаются как полезные, а не как ошибка |
| Отсутствие перекоса        | Один профиль не выигрывает у большинства без причины              |
| Практическая применимость  | После результата понятно, какой проект попробовать                |
